# 🚀 Python Programming Course for Beginners

Welcome to the official repository for our Python programming course! This repository contains all the code examples, hands-on exercises, and practical projects covered from Session 5 through Session 11.

---

##  Course Contents & Structure

* **Session 5 (Loops & Range):** 
  * `for` loop syntax and usage.
  * `range()` function with start, stop, and step parameters.
  * Introduction to nested loops and building multiplication tables.

* **Session 6 (Operators & Conditions):** 
  * Comparison operators (`==`, `!=`, `>`, `<`, `>=`, `<=`) and logical operators (`and`, `or`, `not`).
  * Understanding the distinction between assignment (`=`) and equality (`==`).
  * Practical examples: Calculator, even/odd number checker, and password validation.

* **Session 7 (Strings Deep Dive):** 
  * String concatenation vs f-strings.
  * Indexing and slicing operations.
  * Essential string methods (`.upper()`, `.lower()`, `.strip()`, `.replace()`, `len()`).
  * Name badge generator and string manipulation.

* **Session 8 (Lists Basics & Supermarket):** 
  * Introduction to Python lists, indexing, and item modification.
  * Useful list methods (`.append()`, `.remove()`, etc.).
  * Practical mini-projects including a supermarket management snippet.

* **Session 9 (List Operations & To-Do):** 
  * Looping through lists, utilizing `sorted()`, `len()`, and the `in` keyword.
  * Practice scripts: Highest/lowest number finder and a simple interactive to-do list.

* **Session 10 (Dictionaries & Contacts):** 
  * Working with key-value pairs.
  * Adding, updating, and removing dictionary entries.
  * Looping through dictionary items (`.items()`).
  * Practical projects: Mini contact book and student grade lookup.

* **Session 11 (Functions Basics):** 
  * Writing reusable functions with parameters.
  * The core distinction between `print` and `return`.
  * Extra interactive project: Building a graphical user interface (GUI) application using `tkinter`.
